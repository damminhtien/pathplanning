07 / HOW TO READ A MEASUREMENT

Measure more than speed.

Define the task, validate each route, then report the results.

01

Match the problem

Match map, motion rules, costs, robot shape, and goal policy.

02

Freeze the inputs

Record source, version, hashes, seed, and workload.

03

Run a paired comparison

Fix start/goal pairs, protocol, warmups, repeats, and run order.

04

Check independently

Check endpoints, collisions, legal moves, and path cost.

05

Report the results

Show coverage, quality, runtime, memory, and timeouts.

Correctness

Feasible route, exact goal, and independently checked cost.

Time

Median and spread; separate setup when relevant.

Work

Expanded nodes, checked edges, and collision tests.

Memory

Peak use and retained planner state.

Report cohort size and success coverage alongside latency and quality. Shortest-path evaluation contract
